# مانا — سامانه مدیریت مالی شخصی

یک وب‌اپلیکیشن فارسی، راست‌به‌چپ و واکنش‌گرا برای **مدیریت دستی کارت‌های بانکی، موجودی و تراکنش‌ها**. پروژه کاملاً ایستا است و با **GitHub Pages** اجرا می‌شود؛ نیازی به Node.js، پایگاه داده یا فرایند build ندارد.

> **توجه:** مانا یک دفتر حسابداری شخصی است، نه سامانه بانکی واقعی. هیچ تراکنش بانکی واقعی انجام نمی‌دهد و به حساب‌های بانکی متصل نیست.

## امکانات

- ثبت نام با **نام، نام خانوادگی و کد اختصاصی ورود** (حداقل ۸ نویسه)
- ورود با **همان کد اختصاصی** و جداسازی حساب کاربران مختلف در یک مرورگر
- ثبت چند کارت با **شماره ۱۶ رقمی**، عنوان دلخواه و **موجودی اولیه**
- نمایش جزئیات هر کارت با کلیک روی آن
- ثبت **واریزی**: مبلغ، نام و نام خانوادگی فرستنده، توضیحات، تاریخ شمسی و ساعت
- ثبت **برداشت** به سه روش:
  - **دستگاه POS**: مبلغ، توضیحات، نوع خرید، تاریخ شمسی و ساعت
  - **خرید اینترنتی**: مبلغ، علت، نوع خرید، تاریخ شمسی و ساعت
  - **کارت به کارت**: مبلغ، شماره ۱۶ رقمی کارت گیرنده، نام و نام خانوادگی گیرنده، علت، نوع خرید، تاریخ شمسی و ساعت
- تقویم اختصاصی **هجری شمسی** با جابه‌جایی بین ماه‌ها، نمایش امروز و انتخاب روز
- محاسبه خودکار موجودی از مجموع تمام واریزها و برداشت‌ها با واحد **تومان**
- داشبورد موجودی کل، واریزی‌ها و برداشت‌های ماه جاری، تاریخچه، جستجو و فیلتر
- امکان حذف تراکنش، حذف کارت و دریافت فایل **CSV** از تراکنش‌های هر کارت
- پشتیبان‌گیری و بازیابی اطلاعات حساب‌ها در قالب فایل **JSON رمزگذاری‌شده**
- طراحی مناسب موبایل، تبلت و رایانه

## اجرای پروژه

فایل **index.html** را از یک سرور محلی یا GitHub Pages باز کنید. برای استفاده از Web Crypto API، محیط باید HTTPS یا localhost باشد. باز کردن مستقیم فایل با پروتکل file ممکن است در بعضی مرورگرها کار نکند.

برای توسعه محلی، در پوشه پروژه اجرا کنید:

~~~bash
python3 -m http.server 8000
~~~

سپس آدرس http://localhost:8000 را باز کنید.

## راه‌اندازی GitHub Pages

1. وارد مخزن **manage_bank** شوید.
2. در **Settings → Pages**، زیر بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه **main** و پوشه **/(root)** را انتخاب کنید و **Save** بزنید.
4. پس از انتشار موفق، آدرس معمول سایت به شکل زیر خواهد بود:

   https://mozdbaranarshiya.github.io/manage_bank/

فایل‌های **index.html**، **styles.css**، **app.js**، **favicon.svg** و **.nojekyll** در ریشه مخزن قرار دارند. نیازی به افزودن کلید API یا اسرار به مخزن نیست.

## محل نگهداری داده‌ها و امنیت

**مخزن GitHub عمومی است؛ در آن اطلاعات مالی خصوصی یا کدهای ورود هیچ‌کس نباید ذخیره شود.** کد برنامه در GitHub قرار دارد ولی نام کاربران، کارت‌ها و تراکنش‌ها در فضای ذخیره‌سازی همان مرورگری که کاربر استفاده می‌کند نگهداری می‌شوند.

- داده‌های هر حساب به وسیله **AES-GCM 256-bit** رمزگذاری می‌شوند.
- کلید رمزگذاری با **PBKDF2 / SHA-256 / 240000 iterations** از کد اختصاصی و salt تصادفی مشتق می‌شود.
- خود کد ورود ذخیره نمی‌شود. کدهای ساده و قابل حدس در برابر حدس زدن آفلاین مقاوم نیستند؛ یک کد قوی و طولانی انتخاب کنید.
- پس از رفرش صفحه برای بازکردن اطلاعات مجدداً کد ورود لازم است.
- حساب‌های یک مرورگر از هم جدا هستند؛ این **احراز هویت سمت سرور یا همگام‌سازی ابری** نیست.
- اطلاعات به‌صورت خودکار بین موبایل، لپ‌تاپ یا مرورگرهای مختلف همگام‌سازی نمی‌شوند. برای انتقال، از صفحه **پشتیبان و امنیت** فایل رمزگذاری‌شده را دانلود و در دستگاه مقصد بارگذاری کنید.
- پاک‌شدن داده‌های مرورگر یا استفاده از حالت ناشناس می‌تواند باعث ازدست‌رفتن اطلاعات شود. مرتب پشتیبان بگیرید.
- **فراموش شدن کد اختصاصی قابل بازیابی نیست.** فایل پشتیبان نیز بدون همان کد باز نمی‌شود.
- فقط از دستگاه‌های مورد اعتماد استفاده کنید. این برنامه برای نگهداری اسرار بانکی مانند رمز کارت، CVV2 یا رمز یک‌بارمصرف طراحی نشده است.

برای ورود چند کاربر از دستگاه‌های مختلف با داده مشترک و همگام‌سازی خودکار، به یک **پایگاه داده، سرور احراز هویت و کنترل دسترسی سمت سرور** نیاز است؛ GitHub Pages به‌تنهایی چنین قابلیتی ندارد.
