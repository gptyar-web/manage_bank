# مانا | مدیریت مالی شخصی

وب‌اپلیکیشن فارسی و واکنش‌گرا برای مدیریت دستی کارت‌ها، واریز، برداشت و گردش حساب با تقویم شمسی. رابط کاربری روی **GitHub Pages** و داده‌ها در **Supabase** نگهداری می‌شوند.

> توجه: این برنامه دفتر مالی شخصی است، نه بانک واقعی؛ هیچ انتقال وجه واقعی انجام نمی‌دهد.

## وضعیت راه‌اندازی

- کد رابط کاربری و اتصال به Supabase در مخزن حاضر است.
- جدول‌های **mana_cards** و **mana_transactions** و سیاست‌های RLS در پروژه Supabase با شناسه **efibfevyiepkwpnobaro** ساخته و بررسی شده‌اند.
- **برای فعال‌شدن ثبت‌نام، Edge Function با نام mana-register باید منتشر شود.** فایل آن در پوشه supabase/functions/mana-register/index.ts قرار دارد.
- برای انتشار سایت، تنظیمات GitHub Pages را مطابق راهنما فعال کنید.

## امکانات

- ثبت‌نام با نام، نام خانوادگی و کد اختصاصی **حداقل ۱۲ نویسه شامل حروف انگلیسی و عدد**
- ورود از دستگاه‌های مختلف با همان کد، بدون دریافت ایمیل از کاربر
- ثبت چند کارت با شماره ۱۶ رقمی و موجودی اولیه و امکان ویرایش کارت
- ثبت واریز با مبلغ، فرستنده، توضیحات، تاریخ و ساعت
- برداشت با POS: مبلغ، توضیحات، نوع خرید، تاریخ، ساعت
- خرید اینترنتی: مبلغ، علت، نوع خرید، تاریخ، ساعت
- کارت به کارت: مبلغ، شماره کارت گیرنده، نام گیرنده، علت، نوع خرید، تاریخ، ساعت
- تقویم هجری شمسی، موجودی خودکار، جستجو و فیلتر تراکنش‌ها
- خروجی CSV و فایل پشتیبان JSON رمزگذاری‌شده با رمز مستقل
- تازه‌سازی اطلاعات از Supabase و طراحی مناسب موبایل

## گام ۱ — انتشار تابع ثبت‌نام در Supabase

به دلیل استفاده از کد اختصاصی بدون ایمیل واقعی، تابع سمت سرور برای ساخت حساب Supabase Auth نیاز است.

### روش GitHub Actions

1. در https://supabase.com/dashboard/account/tokens یک Personal Access Token بسازید.
2. در مخزن GitHub مسیر Settings → Secrets and variables → Actions → New repository secret را باز کنید و مقدار توکن را با نام **SUPABASE_ACCESS_TOKEN** ذخیره کنید. توکن را در فایل عمومی یا پیام قرار ندهید.
3. به بخش Actions بروید و **Deploy Mana registration function → Run workflow** را اجرا کنید.
4. انتشار تابع را در https://supabase.com/dashboard/project/efibfevyiepkwpnobaro/functions بررسی کنید.

### روش خط فرمان

پس از نصب و ورود به Supabase CLI، در ریشه پروژه اجرا کنید:

~~~bash
supabase functions deploy mana-register --project-ref efibfevyiepkwpnobaro
~~~

کلید محرمانه service_role فقط در محیط Supabase Edge Function استفاده می‌شود و در GitHub قرار نمی‌گیرد. تابع با verify_jwt فعال منتشر می‌شود.

## گام ۲ — انتشار GitHub Pages

1. وارد Settings → Pages مخزن شوید.
2. Build and deployment را روی Deploy from a branch قرار دهید.
3. شاخه main و پوشه /(root) را انتخاب و ذخیره کنید.
4. آدرس معمول سایت پس از انتشار:

## امنیت و حریم خصوصی

- اطلاعات کارت‌ها و تراکنش‌ها در Supabase ذخیره می‌شوند؛ در GitHub فقط **سورس برنامه و کلید عمومی anon** وجود دارد.
- جدول‌ها RLS دارند؛ کاربران فقط ردیف‌های متعلق به شناسه خودشان را می‌خوانند یا ویرایش می‌کنند.
- هیچ دسترسی SELECT یا INSERT به نقش ناشناس برای جدول‌های بانکی داده نشده است.
- کلید ورود توسط Supabase Auth بررسی می‌شود و در فایل‌های GitHub ذخیره نمی‌شود. کد ورود را قوی و طولانی انتخاب کنید.
- نام ایمیل فنی هر حساب از یک شناسه مشتق از کد ساخته می‌شود و قابلیت دریافت ایمیل یا بازیابی گذرواژه ندارد.
- داده‌ها به‌صورت سرتاسری رمزگذاری نشده‌اند و مدیر مورد اعتماد پایگاه‌داده می‌تواند داده‌ها را مشاهده کند؛ از ثبت CVV2، PIN، رمز دوم و OTP خودداری کنید.
- پشتیبان‌های فایل JSON با AES-GCM و رمز انتخابی شما محافظت می‌شوند.
- تابع ثبت‌نام برای استفاده پرکاربر در محیط عمومی به محدودیت نرخ درخواست و محافظت ضد ربات نیاز خواهد داشت.
- پروژه Supabase موجود مشترک با سامانه آموزشی است؛ برای جداسازی کامل عملیاتی بهتر است بعداً پروژه جداگانه بسازید.

## پایگاه داده

دو جدول به نام **public.mana_cards** و **public.mana_transactions** در Supabase ایجاد شده‌اند. فایل **supabase/schema.sql** شامل تعریف ساختار و سیاست‌های دسترسی است. نیازی به اجرای دوباره آن در پروژه فعلی نیست.

| جدول | محتوا |
| --- | --- |
| mana_cards | شناسه مالک، شماره و عنوان کارت، موجودی اولیه |
| mana_transactions | شناسه مالک، کارت، نوع و مبلغ تراکنش، تاریخ و ساعت شمسی، جزئیات |

## ساختار

- index.html — صفحه برنامه
- styles.css — طراحی رابط کاربری
- app.js — فرم‌های کارت، تراکنش، تقویم و داشبورد
- cloud.js — Supabase Auth و دسترسی به پایگاه داده
- supabase/schema.sql — مدل داده و RLS
- supabase/functions/mana-register/index.ts — تابع امن ایجاد حساب
- supabase/config.toml — تنظیمات JWT
- .github/workflows/deploy-mana-function.yml — انتشار دستی تابع از GitHub

## اجرای محلی

~~~bash
python3 -m http.server 8000
~~~

سپس http://localhost:8000 را باز کنید. برای استفاده از Supabase دسترسی اینترنت لازم است. داده‌ها برحسب **تومان** و تاریخ‌های تراکنش هجری شمسی هستند.
